COMPONENT: ButtonGroup

Several Buttons in a row with 4px between them, each as wide as its label. The row wraps onto more lines when it runs out of room.

Written as `<ButtonGroup> ... </ButtonGroup>` with Button tags between. It has no attributes of its own.

```component
<ButtonGroup>
  <Button variant="solid" send="Yes, go ahead">Yes</Button>
  <Button variant="ghost" send="No, stop">No</Button>
</ButtonGroup>
```

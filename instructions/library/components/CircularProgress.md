COMPONENT: CircularProgress

A ring with an arc that travels round it without stopping. It has no value: it only shows that something is under way.

Written as `<CircularProgress />`. It holds nothing.

| Attribute | Values | What it does on screen |
|---|---|---|
| size | xs, sm, md, lg, xl | Diameter: about 24, 30, 48, 72 or 90px on a desktop-width window. Default md. |
| color | primary, secondary, tertiary (the theme's three colours), success, warning, error (usually green, amber and red, but each theme sets them) | Colour of the moving arc. Default primary. |

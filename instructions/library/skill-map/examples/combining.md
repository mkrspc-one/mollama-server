WHICH SKILLS GO TOGETHER

How a machine works (a bike, an engine, a printer)
Anatomy draws the whole object; a Flow shows how power, force or signals move through it; a Data table lists the parts; Rich Markdown First shapes the words. A machine with several systems, such as mechanical and electrical, gets a figure or diagram for each. See examples/machine.md.

Anatomy and Hairline Create together
Anatomy draws the whole object in detail. Hairline Create makes one part of it something the user can move, such as a lever, a throttle or a gear. Each makes its own figure.

How a concept or system works (a protocol, a process, an algorithm)
A Flow for each step that needs one, a table for the terms, and a Visual Explainer page when it needs several connected figures to explore. See examples/concept.md.

A process with stages
A Flow for the order and any loops back, a TreeView for what happens inside each stage. See examples/process.md.

An object to build or print (a bracket, a gearbox, a case)
CadSmith Make Model makes the part as a 3D file, with CadSmith Make Mechanism for moving parts and CadSmith Export Model for the file a printer needs; Anatomy draws how it works. Each makes its own piece.

A comparison
A Rich Markdown First table, then a Mermaid chart or a Data table when there are numbers. No figure skill unless asked. See examples/comparison.md.

A plain question
No skill. Answer in words. See examples/plain.md.

Order of work
1. Plan the pieces first: the sections of the answer and each figure, diagram or table, and which skill makes each. Do not deliberate further.
2. Open each skill you need once; an opened skill stays open. Read only the files its page tells you to.
3. Make each piece with its function and fix what the function reports.
4. Write the explanation around the pieces, with a sentence on what each figure shows.
Do not open the same skill or file twice, and do not ask the user to run anything.

When the user names a skill that is not on
Say so in one line and name it with find_skill so they can turn it on; then answer as well as the skills that are on allow.
